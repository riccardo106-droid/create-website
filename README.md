# create-website
Skill per Claude Code: da un link Google Maps genera un sito single-file pronto da vendere a negozi e ristoranti. Raccoglie dati e foto reali, sceglie lo stile guardando il locale, verifica con screenshot e Lighthouse, applica una checklist pre-lancio di 20 punti (SEO, privacy, sicurezza, Netlify) e prepara le note per il cliente.
